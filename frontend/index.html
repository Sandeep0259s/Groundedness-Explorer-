Model

Every model here comes from Ollama itself — nothing is hardcoded. Pull or import any model (ollama pull <name> or ollama create my-model -f Modelfile) and hit refresh to pick it below.

A small model can be fast at captioning but unreliable at direct questions (or vice versa) — kept separate so you can pick a quick model for bulk uploads and a slower, more careful one for questions.

No vision-capable model is pulled yet — images will still be OCR'd, but won't get a visual description or direct visual Q&A. Pull one (e.g. ollama pull moondream) and refresh.

Performance

Control how much of the machine's CPU/GPU the local models are allowed to use — lower it if other programs need headroom, raise it for faster answers.
